🪶 Quiet Paper, applied to Nila

Same parchment surfaces, ink text scale, DM Serif Display headlines, rings instead of borders, and pill buttons, all four options keep the pink/rose identity. The period colour shifts to a crimson so it stays a step apart from whichever pink you pick as the primary action colour.

Home
Phase ring uses a thin accent stroke, not a saturated fill. The save button is a full-width pill, not a FAB, since this is "update today's entry," not "create a new item."
Calendar
Today is a ring, not a filled circle. The day sheet rises as a true paper sheet with a grip handle, logged data in inset parchment rows.
Insights
Cycle length bars and the phase breakdown are quiet ink-toned bars; only "now" gets the accent. Food list reads like a recipe card, not a dashboard.
Settings
Rows on one paper card with hairline dividers, not separate boxes. Sign out keeps the semantic rose, the only place danger-red appears.
